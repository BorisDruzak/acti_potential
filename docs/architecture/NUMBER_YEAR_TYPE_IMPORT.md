# Уникальность регистрационных номеров по году и типу

Запрос пользователя: заменить уникальность номера в целом реестре на ключ
`реестр + календарный год регистрации + тип документа + нормализованный номер`,
затем импортировать ранее выбранные 100 документов `okrug`. SQL Server и исходные
файлы остаются неизменными.

В конфигурации ACTI тип правового акта — справочное поле `type_id`; UUID типа
платформенной формы остаётся частью области. Для форм без этого справочного
значения используется тип платформенной формы. Отсутствующий год имеет отдельную
область 0: текущий год не подставляется в историю. Дата, тип и номер опубликованной
карточки защищены от изменения.

Новая таблица scoped claims хранит составной ключ. Старые registry claims
сохраняются как исторический baseline. При миграции квитанции и исходные значения резервов
не переписываются. В резерв записывается точная область выдачи; привязка к
несовместимой дате/типу отклоняется. Резерв журнала без контекста однократно
получает область при явном назначении карточке; занятость проверяется атомарно, старая неизвестная область сохраняется.
Миграция не выводит дату отменённого резерва из текущей даты его карточки.
Смена даты/типа в черновике не освобождает ранее занятый номер в старой области.

удаляются и не перенумеровываются.
