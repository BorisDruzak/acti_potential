# Личная история работы

`GET /api/v1/users/me/activity` возвращает события вошедшего пользователя из
существующего журнала аудита. Доступен редактору, читателю и администратору после
обязательной смены первоначального пароля. Сервер всегда ограничивает выборку
`actor_id` текущей сессии; переданный клиентом идентификатор пользователя не
влияет на выборку. Общий `/admin/audit` остаётся административным API.

## Параметры и ответ

- `page`: от 1, по умолчанию 1.
- `page_size`: от 1 до 100, по умолчанию 20.
- `category`: необязательный `documents`, `numbers`, `account` или `other`.
  Категории соответствуют префиксам `document.`, `number.`, `auth.`/`identity.`;
  остальные события входят в `other`.
- `since` и `until`: необязательные ISO 8601 datetime с часовым поясом.
  Начало включительно, окончание исключительно. Неверный период возвращает 422.

Ответ: `{items, total, page, page_size}`. Элемент содержит только `id`,
`created_at`, `action`, `object_type`. Поля аудита `details`, `request_source`,
`request_id`, идентификаторы субъектов и объектов не передаются. События
отсортированы по `created_at DESC, id DESC`; число событий использует те же
ограничения пользователя, категории и периода, что и список.

Интерфейс «Моя работа» показывает понятные описания действий и время в часовом
поясе устройства. Даты фильтра преобразуются в границы суток этого часового
пояса. История содержит только уже регистрируемые сервером события; открытие
каждой страницы и ввод текста не превращаются в новые события. Названия и
содержимое документов, а также чужие действия не раскрываются.

## Рабочая навигация

Рабочее пространство и пространство читателя открываются в разделе «Документы».
В меню доступны «Документы», «Моя работа», «Реестр номеров» и «Мой пароль».
Конструктор процессов остаётся в административном пространстве; реализация
процессов, шаблонов и практических случаев сохраняется. Присвоение номера из
карточки документа использует существующий механизм.

Незакреплённая панель появляется у левого края или по кнопке «Меню», затем
скрывается при работе с содержимым. Временное раскрытие не сдвигает страницу
и не перемонтирует её компоненты. Закрепление сохраняется локально для текущего
пользователя и резервирует место под панель на экранах шире 700 px. На узких
экранах панель работает как выдвижное меню с кнопкой закрытия. Скрытая панель
недоступна для фокуса (`inert`), Escape закрывает незакреплённое меню и возвращает
фокус кнопке раскрытия. Учитывается `prefers-reduced-motion`.
