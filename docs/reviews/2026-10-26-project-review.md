## Производительность

Сервисная выдача пяти фрагментов на документ, отдельный синтетический корпус:

| Документов | SELECT до → после | Время до → после, мс |
|---:|---:|---:|
| 1 | 55 → 4 | 148 → 17 |
| 10 | 550 → 4 | 456 → 26 |
| 50 | 2750 → 4 | 2834 → 68 |

Число SQL-запросов закреплено регрессионными ограничениями. Время — отдельные
наблюдения, а не статистическая гарантия. Для административного списка ошибок
число SELECT сократилось с 182 до 4 в сценарии выше.

Дополнительная короткая проверка реального ASGI API через TestClient:
1000 синтетических карточек, страница 20 результатов, поиск по метаданным,
24 запроса на каждый уровень конкурентности после прогрева. Тестовый PostgreSQL
ограничен одним CPU и 512 МиБ; перед итоговым замером другие тестовые прогоны
не выполнялись.

Первый замер, пересёкшийся с полным тестированием, не использован в таблице.

## Ограничения

Код не развёртывался и установщик не устанавливался. Реальная сессия Word,
длительный нагрузочный тест и работа с production-данными не выполнялись.
Проверка не является доказательством отсутствия всех дефектов проекта.

При одновременном rehash одного и того же устаревшего пароля один из входов
может безопасно завершиться отказом и потребовать повторного входа.
Дорогая проверка пароля не удерживает общую блокировку аккаунтов.

Предупреждения относятся к тестовому инструментарию: Starlette сообщает
об использовании httpx в TestClient, pytest — о свойствах измерений
`record_property` при формате JUnit `xunit2`. Закреплённые зависимости
в рамках ревью не менялись.
