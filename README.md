# ACTI

Репозиторий проекта: [BorisDruzak/acti_potential](https://github.com/BorisDruzak/acti_potential).

Актуальная концепция — [ACTI v3: видение и дорожная карта](docs/ACTI_V3_VISION_AND_ROADMAP.md).
Платформенное ядро ACTI v3 реализовано и развёрнуто на основной ВМ: локальный
вход, серверные сессии, роли, PostgreSQL/Alembic, API, аудит, outbox/worker,
файловый провайдер и React web-оболочка. Проверены работа через браузер,
сохранность данных после пересоздания контейнеров и тестовое восстановление БД.
Результаты и ограничения: [приёмка Task 001](docs/architecture/TASK_001_ACCEPTANCE.md).

Старая настольная версия полностью сохранена в [`legacy/v2/`](legacy/v2/) вместе
со своими зависимостями, тестами и установщиком. Реестр v3 и массовая миграция
документов ещё не реализованы; разделы будущих модулей помечены «В разработке».

- [Развёртывание и эксплуатация](docs/DEPLOYMENT.md).
- [Согласованная спецификация ядра](docs/architecture/TASK_001_PLATFORM_FOUNDATION_DESIGN.md).
- [План реализации](docs/architecture/TASK_001_IMPLEMENTATION_PLAN.md).
- Код v3: `backend/`, `frontend/`, `deploy/`; контракт импорта: `migration/`.

- [Правила работы](AGENTS.md).
- [Общие настройки проекта](project.toml).
- [Хранение данных и проверка инфраструктуры](docs/INFRASTRUCTURE.md).

Основная ВМ доступна через локальный SSH-псевдоним `acti-v3`.
Адрес, учётная запись, UUID томов и результаты проверки записаны в локальные
`PROJECT_CONTEXT.local.md` и `project.local.toml`, исключённые из Git.
Для нового рабочего места эти файлы и SSH-доступ настраиваются отдельно.

Под PostgreSQL подготовлен отдельный том 100 ГиБ, под документы — 400 ГиБ.
Подготовка дисков и приёмка приложения — отдельные этапы; текущая приёмка ядра
зафиксирована в отчёте Task 001. Адрес доступа, сертификат доверия и данные
первоначальной настройки передаются локально и не публикуются в Git.
